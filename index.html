You found a secret server located under the deep sea. Your task is to hack inside the server and reveal the truth.

TL;DR
Agent Sudo is an easy-difficulty boot2root room on TryHackMe. The exploitation chain starts with web reconnaissance and discovering that custom HTTP User-Agent headers redirect to an internal page revealing an agent’s username. Brute-forcing the FTP service yields credentials and two steganographic images containing embedded archives and messages. Extracting the hidden data via binwalk and steghide reveals SSH credentials for user james . Finally, analyzing sudo privileges reveals a misconfiguration exploitable via CVE-2019-14287 ( sudo -u#-1 /bin/bash ), granting instant root privileges.

Mira sent her research results from MIRA-NODE to INGGID-HUB. The gateway reported the transfer was successful, but the file never arrived at the receiver’s end. The only remaining artifact is penelitian.pcap . Trace the communication between the two devices, reconstruct the transmitted data, and find what is hidden within the research findings.

TL;DR
The research file was transmitted as 24 AES-128-CBC encrypted chunks over MQTT. The AES key was wrapped using INGGID-HUB’s RSA-1024 public key. Both devices (MIRA-NODE and INGGID-HUB) generated their RSA keys using a shared prime due to an outdated demo prototype configuration.
