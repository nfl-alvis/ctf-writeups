Uploader

 spawn2pwn published on 2026-04-26 included in Web and NCKUCTF

A file upload portal that hosts submitted assets in a public directory. Can you leverage this service to gain arbitrary code execution?

TL;DR
Uploader is a web exploitation challenge highlighting an Unrestricted File Upload vulnerability resulting in Remote Code Execution (RCE). The application calculates a SHA-1 hash of the uploaded file’s content for the filename, but preserves the original user-supplied file extension and stores the file in an executable public directory ( /upload/ ). Uploading a simple PHP webshell ( <?php system($_GET['cmd']); ?> ) enables command execution and reveals the root flag.

Shiba Shop

 spawn2pwn published on 2026-04-25 included in Web and NCKUCTF

Welcome to the Shiba Shop! Choose your favorite companion. Some special items might require deep pockets… or a clever bypass.

TL;DR
Shiba Shop is a web security challenge that demonstrates the dangers of client-side trust and missing server-side validation. By intercepting the HTTP POST purchase request with Burp Suite and tampering with the hidden form parameters (item_id=5430&cost=0), an attacker can acquire the locked high-cost FLAG item without having sufficient wallet balance.

Challenge Overview

The application simulates a pet shop where users can purchase different varieties of Shiba Inu using their wallet balance.

Summary

This challenge exposes a Sinatra-based image processing application that accepts two main inputs:

  1. image file uploaded by the user
  2. transformation metadata in key: value format

The main vulnerability lies in the use of instance_eval against strings constructed directly from user metadata. Even though the application tries to apply a simple blacklist to the metadata, the implementation still allows Ruby code injection via the directive or key metadata section.
